Regeln für die Ziehung
Karten festhalten oder ausschließen

Festgehaltene Karten kommen in jede Ziehung. Ausgeschlossene Karten bleiben aus dem Vorrat.

    2. Für Dominion kopieren

      Füge die fertige Zeile ins Kartensuchfeld der Kingdom-Auswahl im Spiel ein.

      3. Stapel verdoppeln (optional)

      Der Code verdoppelt alle zehn gezogenen Königreichstapel. Speichere den Code als eigenes Set in der Profildatei und speichere auch das normale Königreich aus Schritt 2 im Spiel. Lade dann das Verdopplungsset, klicke auf „Spielen“ und gib die Partie auf. Entlade das Set in der Kingdom-Auswahl, ohne die Zusatzregeln zu leeren. Lade jetzt das gespeicherte Königreich und starte die Partie.

      Füge den Eintrag in den Bereich <saveSets> deiner profiles.xml ein. Schließe Dominion vorher vollständig und sichere die Datei.

      Direkt in profiles.xml speichern

      Wähle unter Windows die Datei %APPDATA%\TempleGates\Dominion\profiles.xml aus. Der Generator verarbeitet sie lokal und unterstützt hier Dateien mit genau einem Profil.

      In diesem Browser steht direktes Speichern nicht zur Verfügung. Du kannst den XML-Eintrag kopieren und selbst einfügen.
