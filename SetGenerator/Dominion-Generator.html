Erweiterungen und Editionen

0 bis 0 schließt eine Erweiterung aus. Mit der gewählten Stapelzahl als Bis-Wert bleibt die Obergrenze offen. Gleiche Werte verlangen genau diese Zahl.

Regeln für die Ziehung

Anzahl der Stapel je Filter. Die gewählte Stapelzahl als Bis-Wert lässt die Obergrenze offen. 0 bis 0 schließt passende Stapel aus.
